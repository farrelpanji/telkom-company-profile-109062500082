# Telkom University Company Profile

Website company profile sederhana yang dibuat untuk praktikum Pengembangan Web. Project ini menggunakan PHP native dan MySQL/MariaDB, sekaligus menerapkan Git dan GitHub untuk mengelola perubahan kode.

## Fitur
- Halaman beranda dan profil
- Daftar program studi dari database
- Daftar berita dan halaman detail berita
- Formulir kontak untuk menyimpan pesan ke database

## Teknologi
- HTML dan CSS
- PHP native
- MySQL/MariaDB
- XAMPP
- Git dan GitHub

## Cara Menjalankan
1. Pastikan XAMPP sudah terpasang, lalu aktifkan Apache dan MySQL.
2. Salin folder project ke direktori `htdocs`.
3. Buka phpMyAdmin melalui `http://localhost/phpmyadmin`.
4. Buat database `telkom_profile`, lalu impor file SQL yang tersedia di folder `database`.
5. Sesuaikan konfigurasi database pada `config/database.php` jika diperlukan.
6. Buka `http://localhost/telkom-company-profile` melalui browser.

## Catatan
Project ini dibuat untuk keperluan praktikum dan merupakan simulasi company profile, bukan website resmi Telkom University.
